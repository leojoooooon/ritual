## Short Description
*The audio is composed within Ableton Live, centered around the theme of 'Sacrifice,' while the imagery undergoes Chaos processing. The visuals are modulated by the audio interaction, creating a distinct audiovisual experience.*

## Concept / Intent
*Thw project utilizes the Unsplash and Freesound APIs to randomly retrieve audio and visual materials tagged with the keywords 'Nature' and 'Texture.' I view this non-directional acquisition of material as a form of ritualistic data offering.*

## Technology Used
*1.python 2.ableton live 3.p5.js*

## How to Run / Install
