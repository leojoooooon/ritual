# Work 3: Polylization 

A browser-based interactive creative coding installation. This project utilizes Node.js and p5.js to transform landscape photography into a dynamic, physics-driven mosaic grid. Users can interact with the image fragments in real-time through mouse movements.


Follow these instructions to set up and run the project on your local machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation & Setup

**1. Set up the photos directory (⚠️ Important)**

To keep this repository lightweight, original high-resolution photos are not included in the version control. You must manually add your images before running the project:
* Create a new folder named `photos` in the root directory of this project.
* Place your landscape photos (in `.jpg` or `.png` format) inside this `photos` folder.

**2. Install dependencies**

Open your terminal, navigate to the project's root folder, and run the following command to restore the required packages:
```bash
npm install
